Behind the concept.

BALLOON is a former HTML/CSS/Sass learning project, independently rebuilt as a NULLEXWEB portfolio demonstration. It is not a travel operator. No real tours, reservations, reviews or customer relationships are claimed.

Design & development

Concept Project · Designed & Developed by NULLEXWEB.

Custom interface and original SVG balloon mark. System fonts; no external font service or runtime JavaScript dependencies. Build and test dependency licenses are documented in the repository.

Project origins

The original repository documents practice during the course “Advanced CSS and Sass: Flexbox, Grid, Animations and More!” Its old imagery, icon font and video lack provenance in the repository and are excluded from the new production build. Historical files remain available for context.
